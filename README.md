# Romano Leads / Blue Horizon Pools

Lead-generation MVP for Blue Horizon Pools, built with Astro.

## Local development

Requirements:

- Node.js 20 or newer
- npm

Install and run:

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Tests:

```bash
npm test
```

## Environment variables

Copy `.env.example` to `.env` when local runtime configuration is introduced:

```bash
cp .env.example .env
```

Do not commit `.env` or any production credentials. Only variable names and safe example values belong in `.env.example`.
